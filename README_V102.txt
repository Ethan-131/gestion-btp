V102 — IT affiché pour chaque chantier dans une même journée

- Chaque ligne chantier affiche maintenant son IT automatique selon le siège du salarié.
- Avec 2 chantiers dans la journée, les 2 IT sont visibles en même temps.
- Le champ de journée est renommé « IT retenu » : si les 2 IT diffèrent, le salarié choisit la valeur à appliquer.
- Une modification manuelle conserve l’avertissement transmis au bureau/RH.
- Aucun nouveau SQL Supabase requis par rapport à V99/V101.
