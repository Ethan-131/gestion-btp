V103 — Fiches d’heures

- Remplacement des confirmations natives du navigateur par des modales au thème Gestion BTP.
- Confirmation esthétique lors d’un changement de semaine avec modifications non enregistrées.
- Confirmation esthétique avant l’envoi d’une fiche.
- Les confirmations internes de la fiche (journée type / changement de type de journée) utilisent aussi les nouvelles modales.
- Contrôle anti-doublon : si une fiche déjà transmise existe pour le même salarié, la même année et la même semaine, un message bloque un nouvel envoi.
- Les fiches brouillon/refusées/à corriger restent modifiables.
- Aucun nouveau SQL Supabase requis pour V103.
