Gestion BTP — V101

Modification IT :
- l’IT se remplit automatiquement selon le chantier sélectionné et le siège du salarié ;
- le salarié peut modifier manuellement la valeur IT si nécessaire ;
- si la valeur saisie diffère du calcul automatique, un avertissement est affiché au salarié ;
- la fiche est marquée IT à vérifier pour le bureau/RH à sa réception.

Conserve les migrations Supabase V99 pour les IT par siège.
